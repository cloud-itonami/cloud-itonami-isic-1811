# Operator Guide

## First Deployment
1. Register operator, press lines, color/print-specification scope,
   staff and robots.
2. Import existing production and quality-record history.
3. Run read-only specification-scope and press-feed/quality-
   inspection robot mission dry-runs.
4. Configure safety-class allowed sets and human sign-off paths.
5. Publish a dry-run release record and audit export.

## Minimum Production Controls
- color/print-specification-scope validation before any production
  run
- governor gate on every robot action before dispatch
- human sign-off for :high/:safety-critical actions (a print-run
  release without a completed quality inspection, a color/
  specification change outside verified scope)
- evidence-backed release records
- audit export for every dispatch, sign-off and release
- backup manual print-quality review

## Certification
Certified operators must prove robot-safety integrity, color/print-
specification discipline, evidence-backed release records and human
review for release-affecting actions.
